# Installer et lancer francestudents-code-Roblox

[← Les guides](README.md) · [Se connecter](connexion.md)

## Version actuelle

La version 0.1.0 est une reprise du projet en cours de modification. Aucun installateur de cette version n’est publié.

## Lancer depuis les sources

Installe Node.js 22.13.0 ou plus récent et npm, puis exécute depuis le dossier du projet :

```powershell
npm install
npm run desktop
```

Le projet utilise des outils et des ressources différents selon les fonctions activées. Consulte le [guide avancé](avance.md) pour les prérequis de compilation et les détails de développement.

## Windows x64

L’application est distribuée uniquement pour Windows 64 bits.

## Première ouverture

Suis le guide de connexion avec ton **compte FranceStudent**, puis ouvre un dossier pour commencer.
